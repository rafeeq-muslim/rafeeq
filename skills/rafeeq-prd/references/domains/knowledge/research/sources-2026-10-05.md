## 1. HadeethEnc.com (ICSA)

- **Correction:** the Postman link given for HadeethEnc (`documenter.getpostman.com/view/7929737/TzkyMfPc`) is **the IslamHouse API v3 documentation** ✅ (see §6). HadeethEnc's own documentation is at https://documenter.getpostman.com/view/5211979/TVev3j7q; `hadeethenc.com/api-docs/` redirects there ✅.
- **Endpoints** ✅ (base `https://hadeethenc.com/api/v1`, no key):
  - `GET /languages` returns `[{code, native}]`. The list includes **`tl` Tagalog**.
  - `GET /categories/roots/?language=` and `GET /categories/list/?language=` return `[{id, title, hadeeths_count, parent_id}]`. The `list` call returns 414 categories in `tl`.
  - `GET /hadeeths/list/?language=&category_id=&page=&per_page=` returns `{data:[{id,title,translations[]}], meta:{current_page,last_page,total_items,per_page}}`. A root category lists every hadith in its subtree, and `per_page=1000` works.
  - `GET /hadeeths/one/?language=&id=` returns `id, title, hadeeth, attribution, grade, explanation, hints[] (benefits), categories[], translations[], hadeeth_intro, words_meanings[], reference`. Non-Arabic responses add `hadeeth_ar, hadeeth_intro_ar, explanation_ar, hints_ar, words_meanings_ar, attribution_ar, grade_ar`.
  - `GET /hadeeths/multiple/?language=&ids=a,b,…` returns the same fields for many hadith. We used 50 ids per call.
  - `GET /hadeeths/search/?phrase=&language=`
  - **MCP:** `POST https://hadeethenc.com/mcp/` (Streamable HTTP, `MCP-Protocol-Version: 2025-06-18`). Its tools are `get_supported_languages`, `search_hadeeths`, `get_hadeeth_by_id` and `get_hadeeths_by_ids`; `tools/list` was tested.
- **Size** ✅: the root categories list 4,273 / 2,776 / 2,332 entries in ar / en / tl. After removing duplicates across categories there are **3,574 / 2,328 / 1,949** unique hadith.
- **Terms** ✅ (https://documenter.getpostman.com/view/5211979/TVev3j7q): "Contents of the project can be used, with the following terms and conditions: 1. No modification, addition, or deletion of the content. 2. Clearly referring to the publisher and the source (HadeethEnc.com)." The IslamHouse policy README (§6) also names HadeethEnc and allows "search, indexing, RAG, and AI assistants".
- **Decision: Index.** It is the only hadith source with a usable licence in Tagalog, and it carries a grade and the source's own explanation and benefits.
- **Powers:** Ask (level A), `get_hadith`, and KNW-07 benefits (`hints` are the source's own benefits, so cards need selection, not writing).
- **Normalizer:** `hadeethenc.py` ✅.
  - Mapping: `quote_text` = `hadeeth`; `context_text` = `explanation` + `hints`, kept unmodified per plan §3.4; `meta` = grade, attribution, reference, title, words_meanings, `hadeeth_ar` and categories.
  - Origin URL `https://hadeethenc.com/{lang}/browse/hadith/{id}` (returns 200).
  - The API has no version number, so `version` = `api-v1@<fetch date>`.

## 2. Dorar: hadith encyclopedia API

- **Page:** https://dorar.net/article/389/خدمة-واجهة-الموسوعة-الحديثية-API ✅.
- **Endpoint:** `GET https://dorar.net/dorar_api.json?skey=<text>` (optional `&callback=` for JSONP). It returns `{"ahadith":{"result":"<HTML>"}}` with up to 15 results. Each result has the hadith text plus الراوي, المحدث, المصدر, الصفحة أو الرقم and خلاصة حكم المحدث. It has no IDs and no paging, and Cloudflare blocks non-browser user agents (403). Sample code: `dorar.net/files/dorar_api.zip`.
- **Languages:** Arabic only.
- **Terms** ✅:
  - API page: «هي خدمة توفر لأصحاب المواقع والمنتديات عرض نتائج البحث في الموسوعة الحديثية في مواقعهم باستخدام تقنية json».
  - FAQ (https://dorar.net/feedback): «الموسوعات حالياً غير قابلة للتنزيل وإنما هي للبحث والتصفح من خلال الموقع فقط، ولا يسمح بنسخها واستخدامها سواء على جهاز خاص أو أقراص (سي دي)».
  - Footer: «جميع الحقوق محفوظة لمؤسسة الدرر السنية».
- **Decision: Link (unchanged).** The API page grants only displaying search results on websites. It does not grant storage, apps or AI use, and the FAQ forbids copying. A live call would also send the user's text to a third party.
- **Powers:** nothing now. If written permission arrives, a team-only `hadith_grade_lookup` tool (`ai-tools.md` §2.8).
