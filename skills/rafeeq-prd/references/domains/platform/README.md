## الغرض

الأساس الذي تقوم عليه المجالات كلها: بداية سهلة بلغة المستخدم، وحساب اختياري يحفظ هويته، وخصوصية تحميه، وإشعارات لا تكشفه، وتصميم موحّد.

## المصطلحات

| المصطلح | معناه في هذا المجال |
| --- | --- |
| الزائر | من يستخدم رفيق دون حساب؛ تقدّمه محفوظ على جهازه |
| الاسم المعروض | الاسم المستعار الوحيد الذي يراه الآخرون |
| اسم المستخدم وكلمة المرور | للدخول فقط، ولا يظهران لأحد |
| التحقق بخطوتين | رمز يُرسل إلى البريد، لمن يفعّله فقط |
| الوضع الخفي | اسم وأيقونة وإشعارات محايدة لا تكشف أن التطبيق ديني |
| الخروج السريع | زر ينقل فورًا إلى صفحة محايدة |

## يملك ولا يملك

- **يملك:** الحسابات وبيانات الدخول، والموافقات وإعدادات الخصوصية، واللغة واتجاه الكتابة، وإرسال الإشعارات، ونظام التصميم.
- **لا يملك:** محتوى أي مجال آخر.

## القواعد الثابتة

- **الحساب اختياري**، وكل ميزات التعلّم والأسئلة تعمل دونه.
- **ثلاثة حقول فقط للحساب:** الاسم المعروض، واسم المستخدم، وكلمة المرور، وكلها قابلة للتوليد العشوائي. البريد للتحقق بخطوتين فقط.
- **لا أدوات تتبع إعلانية ولا بيع لبيانات**، ولا خطوط أو مكتبات من جهات خارجية تكشف الاستخدام.
- **الإشعارات محايدة افتراضيًا** على شاشة القفل.
- **يحذف المستخدم حسابه وكل بياناته** متى شاء.
- **كل شاشة تدعم اتجاهي الكتابة**، والعربية والإنجليزية والتاغالوغية في النسخة الأولى.
