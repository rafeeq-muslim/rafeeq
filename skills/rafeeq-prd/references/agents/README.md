# Context pack for AI agents

The human docs in `docs/` are short on purpose: the team already knows the background. This folder holds everything an AI agent needs to work at the same level. Team members don't need to read it.

## Read order

| When you are… | Read |
| --- | --- |
| Starting any task | `../00-start-here.md`, `rules.md`, `../domains.md` |
| Drafting or expanding a feature | + `writing-features.md`, `../features.md`, `../personas.md`, the domain card, `glossary.md` |
| Writing code | + the feature document, `glossary.md` (code terms), `sources.md` (licenses), `context.md` (stack) |
| Building or reviewing UI | + `../../design-system/DESIGN.md`, `../design-system.md`, `../design-system/copy.md`, and the skill `../../skills/rafeeq-design-system/SKILL.md` |
| Writing the deck, video script or claims | + `evidence.md` (only cite numbers listed there, with their caveats), `context.md` (judging criteria) |
| Unsure why something is the way it is | `decisions.md` |

## Files

| File | Contents |
| --- | --- |
| `rules.md` | Binding rules: Sharia/content safety, AI assistant, motivation, privacy, repo hygiene |
| `context.md` | The challenge, judging criteria, deliverables, team, decisions so far, technical direction |
| `sources.md` | Approved sources, licenses, and whether we may index or only link |
| `evidence.md` | Citable numbers with sources and reliability |
| `decisions.md` | Decision log with reasons, and open questions |
| `glossary.md` | Shared vocabulary (Arabic and code terms) and domain events |
| `writing-features.md` | How to draft, expand and review features |
| `research/` | Full research reports (Oct 4, 2026) |
