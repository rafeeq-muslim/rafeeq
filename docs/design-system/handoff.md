# مواصفات تسليم الشاشات

مواصفات الشاشات الأربع المرجعية في المعرض (`?tab=screens`)، بقالب مهارة `design-handoff`. الهدف ألا يخمّن المبرمج شيئًا. القيم كلها رموز من [`DESIGN.md`](../../design-system/DESIGN.md)، والمكوّنات من [`design-system.md`](../design-system.md).

**مشترك بين الشاشات:**
- عرض التصميم 390px، وهوامش جانبية 16px (`px-4`).
- عمود واحد، ومسافة 16px بين الكتل (`gap-4`).
- من 768px فما فوق يتوسط العمود بعرض أقصى 480px. لا تصميم للحاسب في التحدي.
- كل شاشة تُختبر بالعربية (من اليمين) والإنجليزية والتاغالوغية (من اليسار)، وبالمظهرين.
- الحركة 200ms بمنحنى `ease-rafeeq`، وتُلغى عند `prefers-reduced-motion`.

## 1. الرئيسية

**الغرض:** أن يعرف المستخدم في ثانيتين أين وصل وما خطوته التالية، وأن يصل إلى السؤال أو المرشد بضغطة.

| الترتيب | المكوّن | الخصائص | ملاحظات |
| --- | --- | --- | --- |
| 1 | `AppHeader` | `name` = الاسم المعروض | دون اسم: «السلام عليكم» وحدها |
| 2 | `JourneyCard` | `monthLabel`، `streakDays` | أول ما تقع عليه العين، وهذا مقصود |
| 3 | `LessonCard` | الدرس الحالي من المسار | الزر يفتح الدرس من حيث توقف |
| 4 | `DailyCard` | بطاقة اليوم المعتمدة | تُخفى إن لم توجد بطاقة معتمدة لليوم |
| 5 | `AskComposer` | — | الإرسال يفتح شاشة «اسأل» بالسؤال |
| ثابت | `BottomNav` | `active="home"` | فوق منطقة الأمان السفلية |

| الحالة | السلوك |
| --- | --- |
| تحميل | `Skeleton` بشكل البطاقات، ولا مؤشر دوّار يغطي الشاشة |
| مستخدم جديد بلا تقدّم | `LessonCard` على الدرس الأول بزر «ابدأ»، والسلسلة 0 بلا شارة |
| سلسلة متوقفة | `StreakChip paused`، ونص «درس واحد يعيدها» |
| بلا اتصال | الدرس المحفوظ يعمل، وخانة السؤال معطلة مع «تحتاج اتصالًا لتسأل» |
| اسم طويل | `truncate` في الرأس |

**الوصول:** ترتيب التركيز يتبع الترتيب البصري. `BottomNav` هو `nav` بوسم «التنقل الرئيسي»، والتبويب النشط `aria-current="page"`.

## 2. اسأل

**الغرض:** إجابة موثّقة بلغة السائل، أو إحالة إلى إنسان حين لا تكفي المصادر.

| المنطقة | المكوّن | ملاحظات |
| --- | --- | --- |
| الرأس | عنوان «اسأل رفيق» + `HumanHelpButton` | الزر ظاهر دائمًا |
| المحادثة | `MessageScrollerProvider` > `MessageScroller` > `MessageScrollerItem` | رسالة المستخدم مرساة (`scrollAnchor`) |
| أعلى المحادثة | `AiDisclosure` | لا يُحذف |
| السؤال | `UserMessage` | `dir="auto"` لأن السؤال قد يكون بأي لغة |
| الإجابة | `AssistantMessage sources={[…]}` | لا تُعرض إجابة دون مصدر |
| بلا مصدر أو مسألة شخصية | `ReferralCard` | يُطلق حدث «طلب إحالة إلى إنسان» |
| خطر | `DangerHelpPanel` | يحل محل الإجابة كليًا |
| الأسفل | `AskComposer` | النص أو الصوت |

| الحالة | السلوك |
| --- | --- |
| انتظار الإجابة (أقل من ثانية) | لا شيء |
| انتظار أطول | سطر «رفيق يبحث في المصادر…» بتأثير `shimmer` |
| أكثر من 10 ثوانٍ | «ما زلنا نبحث» مع زر «أرسله إلى مرشدك» |
| خطأ في الخدمة | `Alert warning`: «لم تصل الإجابة. أعد المحاولة، أو أرسل السؤال إلى مرشدك» |
| أول زيارة | `Empty` بثلاثة أسئلة مقترحة من المسار الحالي |

**الوصول:** الإجابات الجديدة تُعلَن بـ `aria-live="polite"`، وشريط المصدر رابط يُقرأ «المصدر: …».

## 3. التمرين

**الغرض:** تعلّم بالممارسة، والخطأ فرصة للتعلّم لا عقوبة.

| المنطقة | المكوّن | ملاحظات |
| --- | --- | --- |
| الرأس | زر رجوع (سهم ينعكس) + `Progress` | التقدّم داخل الدرس |
| السؤال | `h2` بـ `font-heading text-h2` | |
| الخيارات | `RadioGroup` > `ExerciseOption` (2 إلى 4) | الضغط على البطاقة كلها يختار |
| الأسفل | زر «تحقّق» معطل حتى يُختار جواب | يصبح `ExerciseFeedback` بعد التحقق |

| الحالة | السلوك |
| --- | --- |
| صحيح | الخيار `correct`، و`ExerciseFeedback result="correct"`، و+نقاط تعلّم |
| خطأ | الخيار المختار `incorrect`، والصحيح `correct`، والسبب بمصدره. لا تُخصم نقاط ولا «قلوب» |
| خروج في المنتصف | يُحفظ الموضع، ويعود إليه من `LessonCard` |
| آخر تمرين | ينتقل إلى `CelebrationScreen` إن أتمّ الوحدة |

| الحركة | المحفّز | المدة |
| --- | --- | --- |
| ظهور لوحة النتيجة من الأسفل | التحقق | 200ms |
| امتلاء شريط التقدّم | تمرين جديد | 300ms |

## 4. الاحتفال بالوسام

**الغرض:** «ذروة» الوحدة (قاعدة الذروة والنهاية): لحظة فرح تدفع إلى الدرس التالي.

| الترتيب | العنصر | ملاحظات |
| --- | --- | --- |
| 1 | `MilestoneBadge earned` بحجم 132 | يظهر بتكبير خفيف 500ms |
| 2 | شارة كهرمانية باسم الوسام | نصها حبري |
| 3 | العنوان `text-h1` | «أتممت مرحلة …» |
| 4 | إحصاءات `Badge outline` | دروس، ونقاط تعلّم، وسلسلة. لا عبادات أبدًا |
| 5 | زر `celebrate` | الدرس التالي، وهو الموضع الوحيد الذي يكون فيه الكهرماني فعلًا أساسيًا |
| 6 | زر `outline` «شارك فرحتك» | المشاركة صورة بلا اسم المستخدم الحقيقي |

**ثابت:** السطح حبري دائمًا (الشاشة تفرض رموز الوضع الداكن). لا صوت ولا موسيقى. تظهر مرة واحدة لكل وسام.

## حالات حدّية لكل الشاشات

- **النص الطويل:** الأزرار لا تقص النص؛ تلتف إلى سطرين. العناوين `text-balance`.
- **الأرقام الكبيرة:** `1,240` بفاصلة الآلاف اللاتينية و`tabular-nums`.
- **الاتصال البطيء:** تظهر إشارة قبل مضي ثانية، والدروس المحفوظة تعمل دون اتصال.
- **البيانات الناقصة:** كل مكوّن يقبل غياب الحقول الاختيارية دون فراغ مكسور (بطاقة اليوم تُخفى، والاسم يُحذف من التحية).
- **قارئ الشاشة:** كل أيقونة بلا نص لها `aria-label`، والحالات تُقرأ («مقفل»، «الدرس الحالي»، «إجابة صحيحة»).
