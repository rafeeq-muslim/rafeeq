# الممارسة اليومية (`PRC`)

| النوع | المالك |
| --- | --- |
| داعم | ناصر بن خالد العويمر |

## الغرض

أدوات يومية تعين المسلم الجديد على عيش دينه: يعرف وقت الصلاة واتجاه القبلة، ويستعد لرمضان، ويبني عاداته الحسنة بالتدريج.

## المصطلحات

| المصطلح | معناه في هذا المجال |
| --- | --- |
| طريقة الحساب | طريقة حساب مواقيت الصلاة، وتُختار حسب البلد (أم القرى في المملكة) |
| العادة | سلوك يريد المستخدم بناءه، يسجّل التزامه به يوميًا |
| العادة التعبدية | عادة هي عبادة (صلاة، صيام، ذكر، قراءة قرآن): **تُتابع سرًّا دون أي مكافأة** |
| العادة غير التعبدية | عادة تعلّم أو خُلق أو حياة يومية: يُعدّ التزامها على الجهاز، ولا يُرسل إلى التحفيز (قرار PRC-02، اعتمده مالك المنتج 2026-10-06) |
| تخرّج العادة | إعلان أن العادة صارت ثابتة، فتتوقف متابعتها اليومية ويبقى سجلها |

## يملك ولا يملك

- **يملك:** مواقيت الصلاة وإعداداتها، والتقويم الهجري ووضع رمضان، والعادات وسجلاتها وتخرّجها.
- **لا يملك:** النقاط والأوسمة (التحفيز)، وتوقيت الإشعارات وإرسالها (المنصة).

## القواعد الثابتة

- **المواقيت والقبلة تُحسب على جهاز المستخدم**؛ موقعه لا يُرسل إلى خوادمنا ولا إلى أي جهة.
- **العبادات تُتابع سرًّا دون نقاط ولا أوسمة ولا ترتيب**، ولا يراها أحد غير المستخدم.
- **تخرّج العادة يقرره المستخدم** بعد مدة التزام كافية، ويمكنه التراجع عنه. ولا يعني تخرّج عبادة أنها لم تعد واجبة.
- **بداية رمضان «متوقعة»** حتى يُعلن ثبوتها، مع تنبيه بفارق يوم محتمل.
