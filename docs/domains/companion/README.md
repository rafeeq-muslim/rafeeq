# المرافقة والمجتمع (`CMP`)

| النوع | المالك |
| --- | --- |
| أساسي | يُحدد لاحقًا |

## الغرض

لا يُترك المسلم الجديد وحده: يصل إلى إنسان حين يحتاج، ويتابعه مرشد يختاره، ويجد صحبة آمنة تشاركه لغته وتجربته.

## المصطلحات

| المصطلح | معناه في هذا المجال |
| --- | --- |
| طلب المساعدة | رسالة يرسلها المستخدم إلى إنسان عبر زر «أريد إنسانًا» |
| الطلب العاجل | طلب ناتج عن حالة خطر، يُعرض معه رقم مساعدة فورًا |
| المرشد | مسلم متطوع معتمد يتابع عددًا محدودًا من المستفيدين |
| صندوق المرشد | المكان الذي يرى فيه المرشد الطلبات ويرد عليها |
| المجموعة | عدد صغير من المسلمين الجدد يشتركون في اللغة والجنس، بإشراف مرشد |
| البلاغ | إخطار المشرف برسالة مسيئة أو مريبة |

## يملك ولا يملك

- **يملك:** طلبات المساعدة وحالتها، وعلاقة المرشد بالمستفيد، والمجموعات ورسائلها، والبلاغات.
- **لا يملك:** إجابات المساعد (المعرفة والأسئلة)، واعتماد المرشدين (مجال الجهات، مؤجَّل).

## القواعد الثابتة

- **حالات الخطر تُعرض فورًا مع أرقام المساعدة**، ولا تنتظر ردّ مرشد.
- **المرشد يرى ما يأذن به المستفيد فقط.** الطلب العاجل لا يحمل نص السؤال إلا بإذنه.
- **لا مجتمع مفتوح دون إشراف:** المجموعات صغيرة، ولها مرشد، وفيها زر بلاغ.
- **المجموعات من جنس واحد.**
- **يُبلَّغ فورًا عن طلبات الزواج والمال والدعوة إلى جماعات**، فهي أشهر المخاطر على المسلم الجديد.
