# الشخصيات

شخصيات مبنية على البحث (`agents/research/04`)، وهي **مسودات تُتحقق منها بمقابلات** مع مسلمين جدد ومرشدين. الأسماء للتوضيح فقط. استخدمها في القصص: «بصفتي جوزيف…».

> **تنبيه من البحث:** أغلب الدراسات عن المسلمين الجدد غربية، وأغلب عيّناتها نساء (62–65%). أما في الخليج فالمقيمون غير السعوديين 77% منهم رجال، و65% ممن أسلموا في إحصاء سعودي (2016) رجال. لذلك نصمم للخليج أولًا، ولا ننسخ نتائج الغرب كما هي.

## جوزيف — عامل وافد أسلم حديثًا

| | |
| --- | --- |
| **من هو** | رجل في الثلاثين، فلبيني (والجنسيات الأكثر بين المسلمين الجدد في الخليج تختلف من مكتب لآخر: الفلبين، وإثيوبيا وإريتريا، وسريلانكا، والهند، ونيبال). يعمل سائقًا في الرياض. أسلم قبل أسبوعين في مكتب دعوي. |
| **لغته** | التاغالوغية، وإنجليزية بسيطة. لا يقرأ العربية. |
| **وضعه** | ورديات طويلة، ووقت قليل بعد العمل، والدروس بعيدة عن سكنه، وكفيله لا يعينه. جواله معه، لكن وقته ورصيده محدودان. وقد يعود إلى بلده خلال السنة. |
| **ما يحتاجه** | خطوات يومية قصيرة بلغته (كيف يتوضأ ويصلي)، وطمأنة بأن التدرّج مقبول، ومن يسأله دون حرج، وشخص من بلده أو بلغته. |
| **ما يؤلمه** | لا برامج بلغته، والدروس بالعربية فقط، ولا أحد يتابعه بعد يوم إسلامه. |
| **ما يعنيه للتصميم** | دروس من دقائق تتحمل الانقطاع، وصوت أكثر من نص، وعمل مع اتصال ضعيف، ورحلة تستمر إن غادر المملكة. |

## دانيال — أسلم عبر الإنترنت بعيدًا عن أي مجتمع

| | |
| --- | --- |
| **من هو** | شاب في العشرينات، تعرّف على الإسلام بالقراءة والمقاطع، وأسلم عبر محادثة مع منصة حوار. لا يعرف مسلمين في مدينته. |
| **لغته** | الإنجليزية. |
| **وضعه** | يقرأ كثيرًا ويسأل كثيرًا. يشعر بالوحدة، خاصة في رمضان والعيد. |
| **ما يحتاجه** | أجوبة سريعة موثوقة في خصوصية، وصديق مسلم، وطريق إلى مسجد قريب أو مرشد بلغته. |
| **ما يؤلمه** | المحتوى على الإنترنت متضارب، ولا يعرف بمن يثق. |
| **مخاطره** | من يتعلّم وحده دون صلة بمجتمع مسلم أكثر عرضة لمحتوى متطرف. والمسلمون الجدد الأحدث إسلامًا والأقل أصدقاء مسلمين هم الأكثر شعورًا بالوحدة في رمضان والعيد. |
| **ما يعنيه للتصميم** | المساعد الموثّق مع إحالة سهلة إلى إنسان، وصلة مبكرة بمرشد أو مجموعة. |

## ليلى — أسلمت وتواجه رفض أسرتها

| | |
| --- | --- |
| **من هي** | شابة تعيش مع أسرتها، أسلمت وتخفي إسلامها الآن. قد تكون في الخليج أو خارجه. |
| **وضعها** | تخشى أن ينكشف أمرها؛ تصلي سرًّا. قد تتعرض للطرد أو القطيعة أو الحرمان من المال. |
| **ما تحتاجه** | خصوصية تامة، وطريقة هادئة للتفكير في متى وكيف تخبر أسرتها (لا قاعدة واحدة للجميع)، وتذكير بأن العلاقة كثيرًا ما تتحسن مع الوقت، ومساعدة عاجلة إن تعرضت لخطر. |
| **ما يؤلمها** | ضغط بعض المسلمين عليها في أمور ثانوية، والخوف من أن يرى أحد التطبيق على جوالها. |
| **ما يعنيه للتصميم** | حساب دون بيانات تكشفها، وإشعارات ووضع خفي محايد، وزر خروج سريع، وطريق فوري إلى إنسان في حالات الخطر. |

## أبو عبدالله — مرشد متطوع

| | |
| --- | --- |
| **من هو** | مسلم يعمل في وظيفة نهارية، يتطوع مع مكتب دعوي، ويتحدث الإنجليزية. |
| **وضعه** | وقته محدود بعد العمل، ولا يستطيع أن يكون متاحًا طوال اليوم. |
| **ما يحتاجه** | عدد محدود من المستفيدين (5 إلى 10 في التصاميم المقترحة)، ومطابقة باللغة والجنس، وإرشادات واضحة لأسبوعهم الأول، وطريقة لإحالة الحالات الحساسة (أذى، صحة نفسية، تطرف)، وألا يُتوقع منه الرد في كل وقت. |
| **ما يؤلمه** | الاحتراق من كثرة الطلبات، وانقطاع التواصل مع من يرعاه، وأسئلة خارج تخصصه. |
| **ما يعنيه للتصميم** | صندوق طلبات واضح، وسقف لعدد المستفيدين، وملخص لحال كل مستفيد يأذن به، ومسار إحالة للحالات الحرجة. |

## منسّق المكتب الدعوي *(لمجال الجهات، بعد التحدي)*

| | |
| --- | --- |
| **من هو** | موظف في مكتب دعوي أو جمعية توعية جاليات، يتعامل مع جنسيات ولغات كثيرة بعدد قليل من الدعاة والمترجمين. |
| **ما يحتاجه** | سجل لكل مسلم جديد (اللغة، والجنسية، والتواصل)، ومرشدين بلغات المستفيدين، ومعرفة من انقطع مبكرًا. |
| **ما يؤلمه** | قلة الدعاة والمترجمين، وضعف المتابعة بعد الإسلام، ونقص المحتوى ببعض اللغات، وعدم تعاون بعض الكفلاء، وتكرار البرامج بين المكاتب. |
| **فرصة** | أطلقت المملكة في يوليو 2026 بطاقة «مسلم جديد» رقمية عبر توكلنا لتحسين جودة البيانات؛ قد تكون نقطة بداية للربط مستقبلًا. |

---

**ما لا نعرفه بعد ويجب أن نسأل عنه في المقابلات:** امتلاك الجوال وتكلفة البيانات ومستوى القراءة بين العمالة منخفضة الأجر، وهل تدير المكاتب مجموعات واتساب بالفعل، والوقت الأسبوعي المقبول للمرشد، وهل يستطيع مرشد في الخليج متابعة من عاد إلى بلده.
